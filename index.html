PROJECT 01 — KNOWLEDGE GENERATION ENGINE · VARAVOX

AGENTS THAT
GROW THEIR OWN
KNOWLEDGE.

Legal AI, built with Varavox: an autonomous multi-agent system that researches, structures, validates and improves legal knowledge — statutes, contracts, case law — continuously. Four specialized agents — Researcher, Curator, Sentinel, Resolver — run as a closed loop over a wiki-backed knowledge store (no vector DB). The UI is an AI operations console: you watch which agent is working, what it found, and why the next one fires.

PROJECT 02 — AGENT ARENA

TWO AGENTS.
ONE QUESTION.
LET THEM ARGUE.

An experiment in adversarial multi-agent reasoning. Two LLM agents argue opposite sides of a motion in real time while a judge agent scores every round for evidence, logic and persuasion. A good argument beats a single answer: the disagreement surfaces weak claims, hidden assumptions, and the evidence that actually holds up.
